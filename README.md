<img src="https://img.shields.io/badge/-01-0D1117?style=flat-square&color=58A6FF" height="24"/> About Me

I'm Mithun, building a multidisciplinary technical portfolio across AI/ML, data science, cybersecurity, and software development, based in Mumbai, India. I like turning ideas into real, working products rather than one-off assignments — and pursuing hands-on certifications alongside them.

**Currently building**

- **Sign2Speech** — a PyQt6-based ASL gesture recognition desktop application with a Windows 11-inspired glassmorphism dark theme, MVVM architecture, and a CNN+LSTM model targeting 100 common ASL gestures. Built with a four-person student team as a portfolio-first project, with a possible arXiv/Medium publication in the works.
- **ExpenseFlow** — a comprehensive Excel-based financial management application built with VBA, Power Query, and Power Pivot, following a detailed 17-phase specification.
- **Community Skill Exchange Platform** — a planned web application for AI-based freelance team formation across India, using semantic/AI-embedding matching (Google Gemini API), a time-based skill-barter system, and built-in identity verification — both a portfolio project and something intended for real launch.

**Also exploring:** application development, UI/UX, and design tooling.

**Philosophy**

> Write code that is simple to read, easy to maintain, and built to last.
